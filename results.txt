========================================================
Отчёт по моделированию СМО с отказами — 20.06.2024
========================================================

Параметры системы:
  Число каналов (n)         : 3
  Время обслуживания (мс)   : 500
  Интенсивность обслуживания: mu = 0,0020
  Исследуемые интервалы (мс): 150, 120, 100, 80, 60, 50, 45, 40, 35, 30, 25

Описание модели:
  Моделируется многоканальная СМО с отказами (без очереди).
  При занятости всех каналов входящая заявка получает отказ.
  Входной поток и поток обслуживания — пуассоновские.

Методика исследования:
  Для каждого значения lambda проводится симуляция длительностью ~100 с.
  Количество заявок пропорционально интервалу: N = 100000 / interval.
  Экспериментальные показатели вычисляются из накопленной статистики.
  Теоретические значения рассчитываются по формулам Эрланга (лекция №5).

Выводы:
  При малых значениях rho (rho < 3) вероятность отказа мала,
  экспериментальные данные могут отклоняться из-за редкости событий.
  При rho > 3 эксперимент хорошо сходится с теорией.
  Увеличение lambda снижает Q и P0, повышает Pn — система перегружается.
  Графики A и k отличаются только масштабом (k = A / mu = const * A).
